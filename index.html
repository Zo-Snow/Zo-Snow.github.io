Enhancement Two: Data Structures and Algorithms

For my second enhancement, I focused entirely on data structures and algorithms to significantly improve the internal efficiency and optimization of the application. In the original C++ version, the program used a nested loop structure to print out lines of asterisks for the histogram, which created an inefficient time complexity of O(n * m) because the system had to manually loop through every single item frequency count to output characters. My enhancement optimized this by implementing a dynamic data-mapping algorithm that processes data in a single pass, dropping the time complexity down to a clean O(n) for data preparation and offloading the heavy visual rendering workload directly to Chart.js and the browser graphics engine. Furthermore, I displayed search efficiency skills by replacing the original slow linear search that ran at O(n) complexity with an optimized backend module that builds an in-memory key-value dictionary lookup map to achieve a true O(1) constant-time retrieval speed. This change demonstrates my ability to design and evaluate computing solutions through the lens of optimization and time complexity while managing the design trade-offs between backend processing power and frontend display speed to ensure the application remains responsive as the dataset grows. This enhancement aligns directly with Course Outcome 3 by designing and evaluating computing solutions that solve a given problem using algorithmic principles and computer science practices while managing trade-offs, and it supports Course Outcome 4 by demonstrating an ability to use well-founded and innovative techniques and tools to deliver real-world value.

Enhancement Three: Databases

For my final enhancement, I moved away from simple text files where items were repeated and disorganized to implement a professional database system. I implemented a structured database using MongoDB Atlas and the Mongoose framework that stores data with specific fields for the item name, the quantity, and a timestamp so the main dashboard can pull sales data dynamically via a date-filtering dropdown menu. This enhancement is where I truly demonstrate a security mindset and mitigate design flaws by implementing multiple layers of defense split evenly between the UI and the backend database. By replacing free-text inputs on the simulation page with controlled button clicks, I effectively eliminated the risk of bad data or injection attacks, while enforcing strict validation in the search bar and a server constraint that restricts users from purchasing more than ten of a single item per order to ensure data integrity and database stability. This shift proves I can use innovative tools to provide real organizational value while keeping data management and privacy at the forefront. This final enhancement aligns with Course Outcome 5 by developing a security mindset that anticipates adversarial exploits in software architecture to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of resources, and it shows my ability to use well-founded and innovative techniques and tools in computing practices to deliver a solution that accomplishes industry-specific goals matching Course Outcome 4.
