# Zuha Asim - Computer Science Capstone

Welcome to my computer science capstone repository. This repository showcases the systematic evolution of a foundational programming project into a secure, high-performance, cloud web application. 

The core artifact chosen for this transformation is a **Daily Sales Analysis Program** originally built in C++ during my CS-210 Programming Languages course. Over three distinct milestones, this application was completely redesigned, optimized, and migrated to a modern full-stack architecture to demonstrate my versatile capabilities across software engineering & design, data structures & algorithms, and databases.

---

## Repository Structure

This master repository is organized into three distinct enhancement directories:

* **`./Enhancement-1` (Software Design & Engineering):** Ported the original C++ console script into a JavaScript full-stack web application using Node.js, Express, HTML, and CSS. Features a multi-page business dashboard and store simulation layout.
  
* **`./Enhancement-2` (Data Structures & Algorithms):** Replaced inefficient $O(n \times m)$ loop structures and $O(n)$ linear searches with optimized $O(n)$ data-mapping and true $O(1)$ constant-time key-value dictionary lookups. Integrates browser-side Chart.js rendering.
  
* **`./Enhancement-3` (Databases & Security):** Transitioned from flat text files to a persistent cloud database system using MongoDB Atlas and Mongoose. Implemented multi-layered defensive security structures, strict user input validation, and server-side request throttling to ensure maximum data integrity.

## How to Run the Enhancements Locally

Follow these simple steps to run any of the full-stack web enhancements (`Enhancement-1`, `Enhancement-2`, or `Enhancement-3`) on your local machine:

### Prerequisites
Make sure you have downloaded and installed [Node.js](https://nodejs.org/) on your computer.

### Setup Steps
1. Click the green **"Code"** button at the top right of this GitHub page and select **"Download ZIP"**.

2. Extract the downloaded ZIP folder anywhere on your computer.

3. Open your computer's terminal or command prompt, and change directories to the specific enhancement folder you want to view, and then further cd into the "backend" folder of that enhancement.

4. Then run the following command to automatically download the project files: `npm install`

5. Start the application server by running: `node server.js`

### Viewing the App

* **For Enhancement 1 & Enhancement 2:**  Keep your terminal open running the server. Then, go to your file manager, look inside that folder, and double-click the main `index.html` file to open and view the dashboard in your browser.

* **For Enhancement 3:** Keep your terminal open running the server. Open your web browser and type this link directly into the address bar: `http://localhost:3000`
